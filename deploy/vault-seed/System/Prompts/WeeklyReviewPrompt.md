# Weekly Review Prompt

Create a concise weekly Obsidian review from the daily notes.

Include:
- Mood and energy trend
- Recurring behaviors
- Repeated timing patterns: sleep/wake rhythm, work start time, meal/rest timing, long gaps, context switches, and rough duration signals
- What reliably helps the user feel better or work better
- What repeatedly drains energy, creates friction, or causes avoidance
- Projects progressed
- Open tasks
- Wins
- 2-3 specific focus areas for next week

Tone:
- Be direct, kind, and evidence-based.
- Do not invent causes.
- Prefer useful observations over generic self-improvement advice.
- Suggest small changes the user would actually want to try.
